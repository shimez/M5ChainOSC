Web Installer

ChromeまたはEdgeから、M5ChainOSCのファームウェアをAtomS3Rへインストールできます。

Web Installerを開く
PC常駐アプリ不要VRChatなどへ、デバイスから直接OSCメッセージを送信します。
ブラウザーで設定同じネットワーク上のスマートフォンやPCから設定できます。
セットアップ後は単独動作PCとのUSB接続は不要です。別途USB給電は必要です。
