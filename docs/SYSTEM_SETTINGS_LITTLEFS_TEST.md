# システム設定LittleFS移行テスト

Wi-Fi認証情報、OSC送信先、画面回転、Web UI言語をNVSからLittleFSへ移行する機能の実機テストです。

## 1. 旧NVS設定からの移行

1. 旧ファームウェアでWi-Fi、OSC送信先、画面回転、Web UI言語を保存します。
2. ファイルシステムを消去せずに新ファームウェアへ更新します。
3. シリアルログに`[M5OSC][SYSTEM] migration source=nvs target=littlefs result=ok`が出ることを確認します。
4. Wi-Fiへ接続でき、OSC送信先、画面回転、Web UI言語が移行前と一致することを確認します。
5. 再起動後も同じ設定が復元されることを確認します。

## 2. 各保存経路

- AP ModeからWi-Fiを保存し、再起動後に接続できる
- OSC送信先を変更して「すべての設定を保存」し、再起動後も維持される
- 画面の向きを変更し、再起動後も維持される
- Web UI言語を変更し、再起動後も維持される
- 全体設定JSONをインポートし、OSC送信先、画面回転、Web UI言語が復元される

各操作時に`[M5OSC][SYSTEM] operation=save`ログが`result=ok`となり、ファイルサイズ、LittleFS総容量、使用量、空き容量が表示されることを確認します。

## 3. Wi-Fi設定の削除

1. OSC送信先、画面回転、Web UI言語を初期値以外へ変更します。
2. Wi-Fi設定を削除します。
3. AP Modeで再起動することを確認します。
4. Wi-Fiを再設定し、OSC送信先、画面回転、Web UI言語が維持されていることを確認します。

## 4. 全設定の初期化

1. AtomS3R本体画面を10秒間長押しします。
2. 再起動後にAP Modeとなることを確認します。
3. OSC送信先、画面回転、Web UI言語、保存済みデバイス設定が初期値へ戻ることを確認します。
4. シリアルログに`[M5OSC][SYSTEM] operation=clear`と`result=ok`が出ることを確認します。

## 5. ファームウェア更新

1. 4種類のシステム設定と複数のデバイス設定を保存します。
2. Web Installerまたはmerged firmwareで、ファイルシステムを消去せずに更新します。
3. 更新後もシステム設定とデバイス設定がすべて維持されることを確認します。
