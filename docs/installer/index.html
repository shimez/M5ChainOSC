M5ChainOSC

AtomS3Rへファームウェアを、ブラウザから簡単にインストールできます。

Stable version 1.0.0

Web Installer

AtomS3RをUSBケーブルでPCへ接続し、下のボタンから接続先を選択してください。

このブラウザはWeb Serialに対応していません。ChromeまたはEdgeを使用してください。
  1. AtomS3Rをデータ通信対応のUSBケーブルで接続します。
  2. 「Install M5ChainOSC」を押し、AtomS3Rのシリアルポートを選びます。
  3. 画面の案内に従ってインストールを完了します。
ポートが表示されない場合は、AtomS3R本体のボタンを押しながらUSBへ接続してください。
再インストールや消去を行う前に、必要な設定をWeb UIの「Export Settings (JSON)」でバックアップしてください。
