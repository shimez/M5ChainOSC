M5ChainOSC

AtomS3Rへファームウェアを、ブラウザから簡単にインストールできます。

Stable version 1.6.1

M5ChainOSCは個人が開発する非公式プロジェクトです。M5Stack Technology Co., Ltd.による公式製品ではなく、同社との提携または承認を示すものではありません。

Web Installer

AtomS3RをUSBケーブルでPCへ接続し、下のボタンから接続先を選択してください。

このブラウザはWeb Serialに対応していません。ChromeまたはEdgeを使用してください。 / This browser does not support Web Serial. Use Chrome or Edge.
  1. AtomS3Rをデータ通信対応のUSBケーブルで接続します。
  2. 「Install M5ChainOSC」を押し、AtomS3Rのシリアルポートを選びます。
  3. 画面の案内に従ってインストールを完了します。
ポートが表示されない場合は、AtomS3R本体のボタンを押しながらUSBへ接続してください。
再インストールや消去を行う前に、必要な設定をWeb UIの「Export Settings (JSON)」でバックアップしてください。

Quick Installation Guide (English)

Use desktop Google Chrome or Microsoft Edge.

  1. Connect the AtomS3R with a USB cable that supports data.
  2. Select Install M5ChainOSC and choose the AtomS3R serial port.
  3. Follow the on-screen instructions to complete the installation.
If the port is not listed, hold the physical button on the AtomS3R while reconnecting the USB cable.
Before reinstalling or erasing the device, back up important settings with Export Settings (JSON) in the Web UI.

Version History

Version 1.6.1: Encoder、Angle、ToF、JoystickのWeb UIをグリッド配置へ整理し、狭い画面での表示を改善しました。

Version 1.6.0: デバイス単位のプリセットをChainOSCminiと共通の形式へ移行しました。従来のM5ChainOSCプリセットも引き続きインポートできます。

Version 1.5.3: AtomS3R画面の描画範囲を最適化してちらつきを抑え、複数のOSCメッセージを送信した際に内容を順番に確認できるよう改善しました。

Version 1.5.2: OSC Addressの入力検証をすべてのChainデバイス設定へ適用し、保存した設定をJSONから正しく復元できるよう改善しました。

Version 1.5.1: Web UI送信時のタイムアウトを調整し、画面が白く表示されることがある問題を改善しました。

Version 1.5.0: Chainデバイス設定の日本語表示を拡充し、Web UIと日本語ユーザーガイドの用語を統一しました。ユーザーガイドへ各設定パラメータの詳しい解説を追加し、EncoderのIncrementモードでは不要なAbsolute入力設定を非表示にしました。

Version 1.4.0: OSC送信時の画面ちらつきを抑え、Web UIに未保存表示、スクロール位置の維持、デバイス設定の折りたたみを追加しました。設定保存と保存済みデバイスの削除も、画面遷移なしで実行できるようになりました。

Version 1.3.0: Web UIの英語／日本語切り替えと、AtomS3R画面上のバージョン表示に対応しました。Web UIの表示処理を最適化し、繰り返しリロードした際の低速化も改善しました。

Version 1.2.0: 認識したChainデバイスの青色LED表示と、Web UIからの10秒間オレンジ識別表示に対応しました。

Version 1.1.0: Chain ToFの最大距離、範囲外でのOSC送信停止、出力方向の設定に対応しました。
